ABOUT THE PROJECT

About ReadAloud

A local-first reading and listening companion for books, reports and long documents.

ReadAloud combines sentence-synchronised captions, page-style previews and playback controls so readers can listen and keep their place.

How it works

Supported documents are indexed locally by default. Mobile stores its library in SQLite; desktop uses IndexedDB. Device-installed voices can run without a remote speech service. Optional neural speech and some PDF/image extraction features use a service that the user explicitly configures.

What it does not currently provide

ReadAloud does not currently provide user accounts, cloud library storage, cloud backup, cross-device synchronisation or advertising analytics. Supported formats and voice availability vary by platform and configuration.
