Privacy Notice

Effective date: 17 October 2026. This notice describes the current ReadAloud source design. The publisher must verify it against the final release and actual service configuration before publication.

Data stored on your device

Imported text, sentence indexes, page previews, book metadata and reading positions are stored locally in the app (SQLite on mobile and IndexedDB on desktop). Importing does not modify or delete the original file. Removing a book deletes the app's local index, not the original document.

Optional remote processing

On mobile, PDF/image extraction and OCR require a service URL configured by the user; when used, the selected file is uploaded to that service. Desktop may use the configured service for extraction fallback. Do not configure a service you do not trust.

Neural speech

When neural speech is enabled, the current sentence and voice parameters are sent to the configured ReadAloud API, which forwards the request to its configured provider (Azure Speech in the supplied API implementation). The service operator and provider may process request data under their own terms. Review those terms before using the service.

Accounts, analytics and sharing

The current app does not implement accounts, advertising analytics, cloud library synchronisation or cloud backup. Optional service traffic is sent only for the feature selected and endpoint configured by the user. Third-party libraries and operating-system services must be included in the publisher's final privacy review.

Retention and deletion

Local indexed content remains until the user removes a book or clears/uninstalls app data. The API is designed not to retain uploaded documents or generated audio as a library; actual infrastructure logs, backups and speech-provider retention depend on deployment settings and third-party terms. The service operator must configure and disclose these accurately.

Security and contact

Use HTTPS for remote endpoints and only use trusted service operators. For privacy questions or requests, email kweeziperez712@gmail.com and include “ReadAloud privacy” in the subject. Avoid attaching sensitive documents unless necessary.
