## Intended highlights

- Local-first reading library and long-form listening workflow across desktop and mobile.
- Shared reader-core for document validation, normalized text, sentence segmentation, and reader-domain behavior.
- Document import and indexing with lazy loading of full book indexes when a book is opened.
- Sentence-synchronized reading captions and playback controls, using installed system voices where supported.
- Optional Python API for configured document extraction/OCR and neural speech; remote processing requires a service the user trusts.
- In-app About, Privacy, Terms, and proprietary-rights information plus public policy-page source assets.
- Mobile icon asset added to the repository; platform configuration and store rendering still require actual build verification.

## Known release blockers

This pre-release must not be promoted to a production release until all relevant checks in [the release checklist](../RELEASE_CHECKLIST.md) are evidenced. In particular:

- A clean, reproducible npm workspace installation requires a committed npm lockfile.
- Core/API tests, type checks, and desktop/mobile production builds must be run in supported environments and recorded.
- Android and iOS artifacts must be signed with the publisher's real credentials; Windows installer signing must be evaluated for the chosen distribution channel.
- Install size must be measured on actual signed Android and iOS artifacts against the 25 MB installed-size target.
- Real-device import, playback, background audio, upgrade, persistence, accessibility, and failure-mode tests remain release evidence requirements.
- Dependency/security audits, public API deployment controls, privacy/store disclosures, support contact, and legal review must be completed.
- No release binaries or checksums are listed here because no verified release artifacts were supplied.
